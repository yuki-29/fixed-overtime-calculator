# fixed-overtime-calculator

This is a CLI tool that calculates the amount of the fixed overtime allowance (fixed overtime pay) based on the total gross pay.
This tool is designed for use in Japan and is based on Japanese labor laws.

総支給額から、定額残業手当（固定残業代）の金額を計算するCLIツールです。

## 使い方

インストールは不要です。`npx` でそのまま実行できます。

```sh
npx fixed-overtime-calculator
```

実行すると、対話形式で3つの質問に答えるだけで結果が表示されます。

1. 総支給額
2. 月平均所定労働時間
3. みなし残業時間

## 出力例

総支給額30万円、月平均所定労働時間160時間、みなし残業30時間の場合。

```

【単価】
```

## 計算のしくみ

総支給額を T、月平均所定労働時間を H、みなし残業時間を N、基本給を B とします。

割増賃金は `時間給 × 1.25 × 残業時間` で計算されるため、両者の関係は次の式になります。

```
T = B + (B ÷ H × 1.25 × N)
```

## 前提条件

- 入力値の扱いは、総支給額は整数のみ、月平均所定労働時間とみなし残業時間は小数も入力できます。みなし残業時間は60時間までです。
- 実務の慣習に合わせ、基本給は100円単位に切り捨て、差額を定額残業代に加算します。
- **割増率は法定時間外労働の1.25倍のみ**を扱います。深夜割増（25%）、法定休日割増（35%）、月60時間超の割増（50%）は対象外です。固定残業代は法定時間外労働分のみを対象とするのが一般的なためです。
- **総支給額は、割増賃金の基礎から除外される賃金を除いた額**を入力してください。労働基準法37条5項および同法施行規則21条により、次の7つが限定列挙されています。

  家族手当、通勤手当、別居手当、子女教育手当、住宅手当、臨時に支払われた賃金、1ヶ月を超える期間ごとに支払われる賃金

  ただしこれらは**名称ではなく実質で判断**されます。家族手当でも家族数に関係なく一律に支払われるものや、通勤手当でも距離に関係なく一律に支払われるものは、算定の基礎に含めなければなりません。

- 月平均所定労働時間は入力値をそのまま使用します。年間所定休日数からの自動計算は行いません。
- 最低賃金との比較は行いません。

## 固定残業代を設計する際の留意点

**実際の残業時間がみなし残業時間を超えた月は、超過分の割増賃金を別途支払う必要があります**（労働基準法37条1項）。
また固定残業代が有効と認められるには、**通常の労働時間の賃金部分と割増賃金部分を判別できること（明確区分性）**と、**その手当が時間外労働の対価であること（対価性）**が必要とされています（最判平成29年7月7日 医療法人康心会事件、最判平成30年7月19日 日本ケミカル事件）。
なお1時間当たりの賃金額および割増賃金額に1円未満の端数が生じた場合、50銭未満を切り捨て、50銭以上を1円に切り上げる処理が認められています（基発第150号）。本ツールは単価を参考値として端数を丸めずに表示しています。
